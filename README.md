# asterisk
asterisk는 충남과학고등학교 학생들만을 위한 온라인 서비스입니다.

## 구성
asterisk는 학교 생활 정보를 제공하는 cnsh.life와 학생 전용 커뮤니티 asterisk community로 구성되어 있습니다.<br>

```
asterisk
 ├─ cnsh.life
 └─ asterisk community
```

본 리포지토리는 asterisk community의 frontend를 다루고 있습니다.
